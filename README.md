# Mi Portafolio

Este proyecto es un portafolio personal desarrollado con React y Tailwind CSS. Permite mostrar información relevante sobre tu perfil profesional, habilidades, formación académica y medios de contacto.

## Estructura del Proyecto

- **src/app/page.js**: Componente principal de la aplicación. Renderiza las secciones del portafolio usando los datos de `data/data.json`.
- **src/app/data/data.json**: Archivo JSON con la información personal, enlaces, habilidades y formación académica.
- **src/components/ui/**: Carpeta con componentes reutilizables como `Card`, `Input`, `Button` y `Carousel`.

## Instalación

1. Clona el repositorio.
2. Instala las dependencias con `npm install`.
3. Ejecuta el proyecto con `npm run dev`.

## Uso

Edita el archivo `data/data.json` para personalizar tu información. Los componentes se actualizan automáticamente con los datos proporcionados.

## Componentes

- **Card**: Muestra información en formato de tarjeta.
- **Input**: Campo de entrada de texto.
- **Button**: Botón estilizado.
- **Carousel**: Carrusel para mostrar habilidades.

## Personalización

Puedes modificar los estilos en los archivos de componentes y en la configuración de Tailwind CSS para adaptar el diseño a tus preferencias.

## Contacto

Para dudas o sugerencias, utiliza el formulario de contacto incluido en el portafolio.
